# «Лилии» — письмо для Нади

Сайт без сборки и зависимостей: просто папка с файлами.

```
site/
├── index.html      ← все тексты, подписи к фото и путь к музыке
├── css/style.css   ← цвета (в самом верху, блок :root) и оформление
├── js/main.js      ← логика (менять не нужно)
├── photos/         ← фотографии (уже сжаты: ~1.3 МБ вместо 9 МБ)
├── stickers/       ← пуговицы, цветы, купидоны (вырезаны из референсов)
└── music/song.mp3  ← сейчас: лучший кусок White Ferrari (San Holo Remix)
```

## Как заменить
- **Музыка** — в `index.html` найти «МУЗЫКА: ЗАМЕНИ ФАЙЛ ЗДЕСЬ».
  Там готовая строка для оригинала Frank Ocean — White Ferrari:
  файл `music/white-ferrari.mp3`, старт с 2:58 (`data-start="178"`), дальше по кругу.
  `data-start` / `data-end` — с какой и до какой секунды играть.
- **Фото** — положить файл в `photos/` и поменять `src="photos/..."` в `index.html`.
  У фото в главах I–II есть `width`/`height` — впиши реальные размеры нового фото.
  В ленте «Ты» `object-position` задаёт, какая часть фото видна в арке.
- **Тексты** — прямо в `index.html`, каждая глава подписана комментарием.
- **Подпись в финале** — «навсегда твой», можно дописать имя.
- **Цвета** — переменные в начале `css/style.css`.

## Как открыть
Можно открыть `index.html` двойным кликом. Чтобы отправить Наде ссылку на телефон,
папку `site` можно бесплатно выложить, например, на Netlify Drop (app.netlify.com/drop —
просто перетащить папку) или GitHub Pages.
